# Artifact contents

- `protocols/`: frozen construction/selection documents and bounded summaries
- `manifests/`: exact revisions, environment distinctions, export provenance and integrity
- `results/`: original compact evidence, selected capture evidence, separate later null/invalid evidence
- `receipts/`: three frozen/reference projections, their compact four-record examples and exact-revision alias contract
- `scripts/`: offline standard-library validation and regression tests

Start with the reviewer route in the repository README. This package supports inspection of reported evidence and is not a complete native reproduction environment.
