# LifecycleRegimeCI Artifacts

Reviewer-accessible compact artifact package for the EDBT 2027 EA&B paper:

**Understanding Lifecycle Context Requirements for Reproducible Stateful Stream Processing: An Empirical Study**

## Scope

This repository provides compact materials for inspecting the reported empirical analysis:

- case and oracle mappings;
- frozen lifecycle construction descriptions;
- compact result summaries;
- lifecycle relationship mappings;
- receipt/projection examples;
- validation helpers.

## Boundary

This artifact package is **not** a complete native reproduction environment.

It does not claim to provide:

- all raw checkpoints;
- private cluster logs;
- external evidence storage;
- credentials or private infrastructure;
- automatic reconstruction of executions.

A compact receipt is evidence for interpreting a construction. It is not a reconstruction framework.

## Paper relationship

The package supports inspection of the claims and boundaries reported in the paper. Functional reproduction still depends on the exact revision, fixture, toolchain, validity rules, and oracle definitions described by the paper.
